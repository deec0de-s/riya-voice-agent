# 60-90 second demo video script

Record your screen (Windows: Win+G, or OBS; or use Loom/Zoom). Keep it under 90 seconds.
Speak in your own words. This is a guide, not a script to read.

**0:00-0:10 Hook**
"Hi, I'm Disha. For the AI Forward Deployed Engineer internship I built Riya, a voice agent
that qualifies real estate leads and books site visits."

**0:10-0:40 Live call (English)**
Show the web app. Click Start call, speak: "I'm looking for a 2 BHK in Whitefield, budget around
1.3 crore, for my own use." Let Riya ask follow-ups and offer a project. Book a Saturday visit.
Say: "She pulls prices from a database through a function call, then books the visit with
another function call."

**0:40-0:55 Guardrail + other language**
Ask for a discount: "Can you give me 10 percent off?" Riya refuses.
Switch to Hindi or Kannada for one short exchange. Say: "It also works in Hindi and Kannada."

**0:55-1:20 What I learned (this is your edge)**
Show `report.html`. Say: "I ran N test calls. Booking rate was X%. The main failure modes were
(1) ..., (2) ... . I fixed them by ... and booking rate went from X% to Y%."
(Use your REAL numbers. Do not invent any.)

**1:20-1:30 Close**
"Code, README and live demo are linked below. Thanks for watching."

Tips: close other tabs, hide your API key and any notifications, speak clearly, zoom the browser
to 125% so text is readable.
